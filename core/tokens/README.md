# Sea Glass design tokens

`tokens.json` is exported from the Sea Glass v1 design system and is the single source of truth for colours, type, spacing, radius, shapes, sizes, blur, opacity, state and shadows. `palettes.json` holds the full HCT tone sets (hue, chroma, 26 tones per palette); any tone that also appears in `tokens.json` takes the `tokens.json` value.

## Updating

1. Download `tokens.json` from the design system and replace the file here.
2. Run `./gradlew :tokens:generateSeaGlassTokens` from `platforms/android/sdk`.
3. Review the diff of the generated Kotlin and commit both.

`verifySeaGlassTokens` runs before every build (`preBuild`) and in `check`. It fails, listing the files, whenever the committed Kotlin no longer matches these JSON files.

## What gets generated

All files go to `seaglass.tokens.package` under `src/main/kotlin`, start with a `// Generated by seaglass-tokens.gradle.kts` header, and use explicit `public` visibility.

| File | Contents |
| --- | --- |
| `SeaGlassPalettes.kt` | `TonalTones`, `SeaGlassPalettes.Aqua` … `NeutralVariant`, `byKey` |
| `SeaGlassColorSchemes.kt` | `SeaGlassLightScheme` / `SeaGlassDarkScheme` (M3 `ColorScheme`), `SeaGlassExtendedColors` with light and dark instances |
| `SeaGlassTypeScale.kt` | `SeaGlassTextStyles(fontFamily)` with every style, `toTypography()` for the 15 M3 roles |
| `SeaGlassDimens.kt` | `SeaGlassSpacingTokens`, `SeaGlassRadiusTokens`, `SeaGlassSizeTokens`, `SeaGlassBlurTokens` (Dp), `SeaGlassOpacityTokens`, `SeaGlassStateTokens` |
| `SeaGlassShapeTokens.kt` | `SeaGlassCornerSpec` fractions for lens, pebble, tumble, shard, egg |
| `SeaGlassShadowTokens.kt` | Shadow layers per theme (offset, blur, spread, colour, inset) |
| `SeaGlassTokenInfo.kt` | Name, version and the SHA-256 of `tokens.json` |

Units: `px` becomes `dp` (and `sp` for type), unitless line heights become `em`, percentages become fractions. Colour aliases such as `{aqua-80}` are resolved per theme. A new token or family added in the design system shows up automatically on the next generate.

Hand-written files can live in the same package; only files with the generated header are rewritten or removed.

## Configuration

Optional, in `gradle.properties`:

- `seaglass.tokens.dir` — folder holding `tokens.json` and `palettes.json`, relative to the root project (the folder with `settings.gradle.kts`); default `<module>/design-tokens`. In the monorepo layout: `../../../core/tokens`.
- `seaglass.tokens.package` — default `<android namespace>.tokens`
- `seaglass.tokens.srcDir` — default `src/main/kotlin`
